# Blossom Music - Privacy Policy

**Last Updated:** November 9, 2025

## Overview
Blossom Music is a local music player. It does not collect, store, or share any personal data.

## Data Collection
- **NO personal data** is collected
- **NO usage analytics** are collected
- **NO advertising tracking** is used
- All music files remain on your device

## Optional Features
- **BlossomBeam** (WiFi sharing): Requires local network access only
- **Lyrics**: Fetched from LRCLIB (anonymous queries)
- All features are opt-in and local-first

## Permissions
- **Storage**: To access your music files
- **Network**: For optional lyrics and WiFi sharing features only

## Open Source
Blossom is open source (GPLv3). You can audit the code at:
https://github.com/WindingMotor/Blossom-Player
